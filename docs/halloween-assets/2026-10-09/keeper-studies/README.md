# Lanterns Beyond the Grave — nighttime stills

Ten original 16:9 composition mockups, generated using the built-in image_gen tool. The supplied reference guides the dark ink drawing, warm candlelight, and limited palette; the existing lantern keeper guides character identity.

Open gallery.html to compare or comparison.jpg for the numbered sheet. Individual PNGs retain their original generated pixels. Exact prompts and source provenance are in prompts.json. These are stills for selecting a visual direction before animation.
