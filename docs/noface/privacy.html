Privacy policy

NofaceChan uploader · last updated 3 October 2026

Who uses this application

The application is used only by the owner of the YouTube channel @NofaceChan55, to manage that channel. No other people sign in to it.

What it accesses

With the owner's permission, granted through Google's sign-in screen, the application uses the YouTube Data API to upload the channel's videos, set their details (title, description, tags, thumbnail, playlist, privacy and publication time) and list the channel's uploads. It does not read email, contacts, files or any other Google data.

How the data is stored

The access token is stored only on the owner's own server and computer, and is used only for the actions above. Nothing is sold, shared with third parties or used for advertising.

Use of Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and Google's Privacy Policy.

Revoking access

Access can be withdrawn at any time from Google Account permissions.

Contact

Questions can be sent through the NofaceChan channel page.
